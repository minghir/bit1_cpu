# =====================================================================
# Program Suprem 1-Bit: Testează toate cele 11 op-coduri ale procesorului!
# =====================================================================

# 1. LOAD (0001) - Încarcă starea lui RAM[0] în RR
00010000

# 2. JNZ (1001) - Dacă RR este true (1), sare direct la adresa 3. Altfel merge la 2.
10010011

# 3. JMP (0110) - Salt necondiționat la adresa 3 (sare peste pasul de CLR)
01100011

# 4. CLR (1010) - Resetează RR la false (0) (ramură alternativă)
10100000

# 5. OR (0011) - Face OR între RR curent și RAM[1]
00110001

# 6. XOR (0111) - Face XOR între RR și RAM[2]
01110010

# 7. NOT (0101) - Inversează starea lui RR
01010000

# 8. AND (0010) - Face AND între RR și RAM[3]
00100011

# 9. JZ (1000) - Dacă RR este false (0), sare direct la adresa 11 (final)
10001011

# 10. OUT (0100) - Dacă am trecut de JZ, scrie rezultatul RR în RAM[4]
01000100

# 11. HALT (0000) - Oprește execuția procesorului
00000000
